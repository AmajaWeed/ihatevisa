# iHateVisa

Редактор фото на документы (паспорт, виза, стандартные форматы 3x4/2.5x3.5) —
нативное десктоп-приложение на **C++ / Qt6 Widgets**, порт браузерного
прототипа [VisaHater](https://dicebanned.art/Visa/) (dicebanned.art).

## Возможности

- **Форматы документов**: Паспорт РФ (2013), Загранпаспорт РФ (овальная
  виньетка), Шенген виза, фото 3x4 см, 2.5x3.5 см, свой формат. Ширина,
  высота, верхнее/нижнее поле, % лица и размер головы — все связаны и
  пересчитываются друг из друга.
- **Позиционирование по двум точкам**: перетащите красные точки
  «макушка»/«подбородок» прямо на фото — масштаб и положение считаются
  автоматически. Поворот — отдельным слайдером (заблокирован по умолчанию).
- **Удаление фона**: авто-очистка по цвету угла фото + «волшебная палочка»
  (заливка связной области по клику).
- **Коррекция**: яркость/контраст/гамма/насыщенность, чёрно-белое, 3-полосная
  цветокоррекция (тени/полутона/света x CMY).
- **Печать листом 10x15 см**: 2/4/6/8 копий на листе с полями/зазором,
  печать через системный диалог печати или экспорт в JPEG (с корректным DPI).

## Сборка (macOS / Windows)

Требуется Qt6 (Widgets, PrintSupport) и CMake 3.21+.

```
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

На macOS для автономного `.app` (со встроенными библиотеками Qt):

```
macdeployqt build/iHateVisa.app
codesign --force --deep --sign - build/iHateVisa.app
```

## Статус

Первая версия (macOS, собрана и проверена). Windows-сборка пока не
тестировалась (нет доступа к Windows-машине у автора порта) — код пишется
кроссплатформенно (чистый Qt6, без macOS-специфичных API), но нужна
проверка на реальной Windows перед релизом под эту платформу.

Не реализовано пока: захват с камеры, автообновление, .msi/.dmg инсталлятор.
